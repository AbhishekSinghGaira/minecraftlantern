# RGB Minecraft Lantern
RGB Minecraft Lantern


A "Color Adjustable Minecraft Lantern" is a project that recreates the iconic lantern from the video game Minecraft. It allows the user to change the light's color to any hue, rather than being limited to the standard yellow or orange glow.
